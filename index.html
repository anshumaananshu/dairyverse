About this starter app

This is a clean single-file version so you can build first without complicated setup.
Later, we can add manifest.json, sw.js, and an icon to make it installable.
The app saves notes, tasks, and theme in your browser using localStorage.
Once this file works, the next step is to add the PWA files.

Tip: after pasting the code, open the file in your browser and test the buttons.
